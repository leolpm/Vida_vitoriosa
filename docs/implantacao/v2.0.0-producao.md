## 6. Pendencia externa para ativar o EDD

A zona DNS de `atitudelaranja.com` nao e controlada pela conta cPanel usada no deploy. O host `edd.atitudelaranja.com` possui dois registros A:

```text
69.6.212.170
162.241.203.216
```

O primeiro registro e antigo/incorreto e deve ser removido. O host deve permanecer apontando somente para:

```text
162.241.203.216
```

Depois da propagacao:

1. executar AutoSSL para `edd.atitudelaranja.com`
2. confirmar certificado valido para o host
3. habilitar redirecionamento obrigatorio de HTTP para HTTPS
4. validar formulario e login EDD em HTTPS
5. validar sessao compartilhada ao alternar entre os eventos
6. testar em celular fisico antes de divulgar o endereco

Nao reduzir `SESSION_SECURE_COOKIE` para contornar o certificado. Isso permitiria envio inseguro e recriaria o alerta do navegador.
